# Contributing to Recordly

Thank you for your interest in Recordly! 

## How to Contribute
1. Fork the repository.
2. Create a new branch for your feature or bugfix.
3. Ensure your code follows the existing Kotlin and Material 3 design patterns.
4. Test your changes locally.
5. Submit a pull request with a clear description of your changes.

## Bug Reports
If you find a bug, please open an issue and include:
- Your device model and Android version.
- Steps to reproduce the bug.
- Logcat output if possible.

Thank you for helping make Recordly better!
