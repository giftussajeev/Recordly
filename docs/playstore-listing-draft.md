# Recordly Play Store Listing

## App Name
Recordly: Clean Screen Recorder

## Short Description
A lightweight, no-ads screen recorder for Android. Records your screen locally with zero tracking.

## Full Description
Recordly is a simple, privacy-focused screen recorder built with Material 3 for modern Android.

What it does:
- Records your screen as MP4
- Configurable resolution (720p / 1080p / 1440p / Native)
- Quality presets (Low / Balanced / High / Max) with smart bitrate
- Match display FPS or choose 30 / 60 / 90 / 120
- Internal audio capture (Android 10+)
- Microphone audio recording
- Floating overlay controls with timer
- Built-in recordings library with search and multi-select
- Custom save location via folder picker
- Saves to Movies/Recordly by default
- Theme: System / Light / Dark / AMOLED
- Material You dynamic colors (Android 12+)

What it doesn't do:
- No ads, ever
- No analytics or tracking
- No internet connection required
- No data leaves your device

Current version: 1.9

Android 8.0+ required. Internal audio capture available on Android 10+.
