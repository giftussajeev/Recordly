# Recordly Play Store Listing

## App Name
Recordly: Clean Screen Recorder

## Short Description
A premium, lightweight screen recorder for Android. No ads, no analytics.

## Full Description
Recordly is a beautiful, Material You inspired screen recorder built for modern Android devices. 

Features:
- Record up to 240 FPS for slow-motion editing.
- Save to native resolution or custom up to 1440p.
- High bitrates up to 35 Mbps.
- Internal Audio capture (Android 10+).
- Secure floating overlay controls.
- 100% offline, privacy-focused, zero ads, zero tracking.

Recordly handles hardware compatibility honestly. We won't fake capabilities your device doesn't support.
